# PDF LoveR 1.5.1

ปรับเครื่องมือหมุน PDF เป็นปุ่มไอคอน **หมุนซ้าย / หมุนขวา** กดซ้ำได้ทีละ 90°
เริ่มต้นที่ทิศเดิม กดสองครั้งกลับหัว สี่ครั้งกลับทิศเดิม มี tooltip เมื่อชี้เมาส์หรือโฟกัสด้วยคีย์บอร์ด
หน้าที่เลือกในแต่ละไฟล์ใช้มุมสะสมร่วมกัน และตรวจภาพก่อน–หลังก่อนบันทึกสำเนา PDF

เครื่องมือพร้อมใช้ยังเป็น 6/34 เหลือพัฒนา 28; จัดระเบียบ PDF เป็นงานถัดไป
ชุดแจกอยู่ใน `dist/PDF_LoveR_1.5.1/` มี EXE, Portable ZIP, installer, คู่มือไทยและ SHA256
repository คง Private และไม่ได้สร้าง GitHub Release
