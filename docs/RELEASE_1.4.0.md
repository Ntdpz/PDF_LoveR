# PDF LoveR 1.4.0

เพิ่ม **แยกหน้า** และ **ลบหน้าออก** รวมเป็น 5 เครื่องมือพร้อมใช้จาก 34 เครื่องมือ เหลือพัฒนา 29

- แยกหน้าที่เลือกเป็น PDF เดียวหรือหนึ่งไฟล์ต่อหน้า
- ลบหน้าที่เลือกโดยสร้างไฟล์ใหม่ พร้อมจำนวนหน้าที่เหลือและป้องกันลบทุกหน้า
- ใช้ตัวเลือกช่วงหน้า/ภาพตัวอย่างร่วม ตรวจเลขหน้าใหม่กับหน้าเดิมและชื่อไฟล์ก่อนบันทึก
- ตรวจต้นฉบับและชื่อชนอีกครั้งก่อนบันทึก ไม่ทับไฟล์เดิม คืนไฟล์ของงานเมื่อเกิดความล้มเหลว
- ย้ายการอ่านข้อมูล PDF และตรวจชื่อ Windows ไป `core/document.py`; เพิ่ม `core/pdf_output.py`

ชุดแจกอยู่ใน `dist/PDF_LoveR_1.4.0/`: EXE, Portable ZIP, installer, คู่มือไทยและ SHA256
repository คง Private และไม่ได้สร้าง GitHub Release
