# PDF LoveR 1.3.0

วันที่ 2 ตุลาคม 2026 (Asia/Bangkok) · ชุดแจกในเครื่อง `dist/PDF_LoveR_1.3.0/`

เพิ่มแยก PDF: หนึ่งไฟล์ต่อหน้า, แต่ละช่วงหน้า และทุก N หน้า พร้อมภาพตัวอย่างหน้า
กลุ่มผลลัพธ์และชื่อไฟล์ก่อนบันทึก เลือกหลายหน้าด้วยภาพหรือพิมพ์ช่วง
ตรวจหน้าซ้ำ ลำดับ จำนวนหน้า ชื่อ Windows ต้นฉบับและไฟล์เดิม
อ่าน PDF ใน worker, ตรวจชุดไฟล์ชั่วคราวก่อนเผยแพร่ และคืนไฟล์ของงานเมื่อบันทึกล้มเหลว

ตัวเลือกหน้าและ worker ภาพตัวอย่างเป็นส่วนกลางสำหรับเครื่องมือถัดไป
รักษา Canvas และ animation การลากการ์ดรวม PDF เดิม ตอนนี้พร้อมใช้ 3 จาก 34 เครื่องมือ
แยกหน้า ลบหน้า จัดระเบียบ และเครื่องมืออีก 28 รายการยังอยู่ในแผน

การตรวจ: 34 unit tests, 7 ชุด native UI checks, ตรวจภาพผลลัพธ์ด้วย Poppler,
920×700 และ scaling 125%, ต้นฉบับไม่เปลี่ยนและกรณีชื่อชนระหว่างบันทึก
ดู [หลักฐานแยก PDF](split-verification.json), [การลากการ์ด](drag-performance-1.3.0.json)
และ [การตรวจชุดแจก](distribution-1.3.0.json)

ชุด EXE, Portable ZIP และ installer รัน PNG → merge → split รวมทั้ง thumbnail process
โดยไม่มี Python ใน PATH; ถอนติดตั้งแล้วไฟล์ผลลัพธ์ยังอยู่ SHA256 อยู่ในชุดแจกและรายงาน
ทดสอบบน Windows 10 x64 ยังไม่มีผลจากเครื่อง Windows 11 แยกต่างหาก; installer ยังไม่มีลายเซ็น
