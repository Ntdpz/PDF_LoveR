# ใส่ลายน้ำ PDF · 1.14.0

เลือกเครื่องมือ **ใส่ลายน้ำ** แล้วเลือก PDF หนึ่งไฟล์ เลือกทุกหน้าหรือช่วงผ่านตัวเลือกหน้าร่วม เช่น `1-3,5` ตั้งลายน้ำ แล้วเปิดแท็บ **ตรวจลายน้ำ** ใช้ปุ่มก่อนหน้า/ถัดไปตรวจหน้าที่เลือกก่อนกด **ใส่ลายน้ำและบันทึก PDF ใหม่** เลือกโฟลเดอร์และชื่อใหม่ที่ยังไม่มีอยู่ โปรแกรมไม่แก้ต้นฉบับและไม่ทับไฟล์เดิม

## ข้อความและภาพ

- ข้อความไทย/อังกฤษหนึ่งบรรทัด 1–500 ตัวอักษร ขนาด 6–144 pt สี `#RRGGBB`
- ฟอนต์ Noto Sans Thai หรือ Serif พร้อม fallback ไทย โปรแกรมฝังฟอนต์ใน PDF ใช้ Noto Sans Thai ที่แจกได้ตาม SIL OFL ใน `pdf_lover/assets/fonts/OFL.txt` ไม่ต้องติดตั้งฟอนต์ในเครื่องผู้เปิด PDF ผลไทยตรวจด้วย Poppler renderer/ตัวอ่านข้อความอิสระบนเครื่องพัฒนา ยังไม่ได้เปิดบนอีกเครื่องจริง
- เลือกภาพ PNG/JPG/JPEG สมบูรณ์ ไม่เกิน 20 MiB และ 16 ล้านพิกเซล PNG เก็บ alpha โปร่งใส ตรวจไฟล์และ decode ใน worker ก่อนใช้งาน ไม่ย่อหรือบีบอัดแบบสูญเสียคุณภาพเอง ภาพที่เกินขอบเขตต้องเตรียมใหม่ด้วยตนเอง
- ความทึบ 0–100%: 0 มองไม่เห็น, 100 ทึบเต็ม สำหรับ PNG เป็นความทึบเพิ่มเติมคูณกับ alpha เดิม สีและฟอนต์ใช้เฉพาะข้อความ
- มุม −180 ถึง 180° ค่าบวกทวนเข็มนาฬิกาบนหน้าที่มองเห็น ค่าลบตามเข็ม

## ตำแหน่ง ขนาด หน้าหมุน และ CropBox

มี 9 ตำแหน่ง: บน/กลาง/ล่าง × ซ้าย/กลาง/ขวา พิกัดอ้างอิง **พื้นที่ CropBox ที่มองเห็นหลังหมุนหน้า** ไม่ใช่ MediaBox ที่อยู่นอกพื้นที่แสดงผล ลายน้ำจึงมีทิศเดียวกับผู้มองเมื่อหน้าเดิมหมุน 0/90/180/270° และคงการหมุน CropBox/MediaBox ของต้นฉบับไว้

กรอบลายน้ำหลังหมุนเว้นขอบหน้าที่มองเห็นอย่างน้อย 12 pt (ประมาณ 4.23 mm) ข้อความใช้ขนาดคงที่เป็น pt ทุกหน้า กรอบข้อความรวมพื้นที่เผื่อสระ/วรรณยุกต์และความสูงบรรทัด จึงมีระยะจากขอบกรอบถึงตัวอักษร ภาพใช้ **ความกว้างเป็นเปอร์เซ็นต์ของความกว้างแต่ละหน้าที่มองเห็นก่อนหมุนลายน้ำ** และคำนวณความสูงจากสัดส่วนภาพเดิม เช่น ภาพ 2:1 ตั้ง 40% บนหน้า 600 pt จะกว้าง 240 pt สูง 120 pt ก่อนหมุน บนหน้าขนาดต่างกันภาพจึงมีขนาดจริงต่างกัน

หากกรอบหลังหมุนไม่พอดีขอบ 12 pt จะปฏิเสธหน้านั้นและคืนไฟล์ชั่วคราวทั้งงาน ให้ลดขนาดข้อความ/ความกว้างภาพหรือเปลี่ยนมุม โดยไม่ลดขนาดให้อัตโนมัติ แม้ตั้งภาพ 100% ก็อาจไม่พอดีเพราะยังต้องเผื่อขอบ เอกสารหลายขนาดควรตรวจทุกหน้าที่เลือก ภาพ preview ที่ผิดพลาดจะไม่ถือว่าเป็นผลที่ยืนยันแล้ว

## Preview ความปลอดภัย และคีย์บอร์ด

Preview กับ export เรียก `stamp_page` เดียวกัน เพิ่ม vector text หรือ image XObject ลงหน้าเดิม Preview บันทึก/อ่านกลับเฉพาะหน้าที่ร้องขอก่อน render เพื่อให้การปัดเศษ alpha ของ PNG ตรงกับ PDF ที่บันทึกจริง ไม่โหลดภาพทุกหน้าล่วงหน้า ไม่แปลงทุกหน้าเป็นภาพ และไม่เพิ่ม preview process ใช้ coordinator ร่วมหนึ่งตัว คิว 16/result 4 และ comparison cache 12/6 MiB ตามระบบเดิม

Ctrl+O เลือก PDF, Ctrl+Enter เริ่มบันทึก, Tab เดิน controls และเลื่อนแผงตั้งค่ามาให้เห็น, Enter/Space เปิดเมนู ตัวเลือกหน้ารองรับคีย์บอร์ดร่วมเดิม ระหว่างทำงานมี loader/progress และปุ่มยกเลิก การยกเลิกรอ native call ที่กำลังทำให้จบแล้ว cleanup จึงคืน controls ไม่รับประกันหยุดทันทีระหว่าง decode/save

แผน immutable ผูก signature ของ PDF/ภาพ ตรวจซ้ำก่อนเผยแพร่ ใช้ staging ข้างปลายทางและ exclusive publication/rollback ของส่วนกลาง อ่าน PDF ใหม่เพื่อตรวจจำนวนหน้าและ geometry ก่อนส่งผล แสดงข้อผิดพลาดเมื่ออ่านภาพไม่ได้ ค่าผิด ภาพเปลี่ยน หรือชื่อชน เลือกไฟล์ใหม่เมื่อมีการเปลี่ยนต้นทาง

คง text/vector/images, links, bookmarks, annotations และ forms เดิม ฟอร์มยังแก้ไขได้ ลายน้ำเป็น overlay ใหม่ อาจทับข้อความในเชิงการมองเห็น; widget/annotation ที่ PDF viewer วาดแยกอาจอยู่เหนือ overlay ข้อความที่เอียงอาจถูกตัวอ่านข้อความเรียงเป็นหลายส่วน (Poppler `-raw` ช่วยอ่านลำดับข้อความ แต่สระไทยที่จัดรูปอาจแยก Unicode และวรรณยุกต์บางตัวอาจไม่ถูกคืนโดย text extraction แม้ภาพแสดงถูกต้อง; ไม่รับรองการ copy/search ลายน้ำไทยตรงทุกตัวอักษร) ไม่ใช่เครื่องมือลบลายน้ำ ไม่ใช่ redaction หรือการป้องกันคัดลอก รับ PDF ที่ไม่ต้องใช้รหัสผ่าน ไม่รับรองลายเซ็นดิจิทัลและ PDF scripts หลังบันทึกใหม่

## หลักฐานและขอบเขต

ตรวจ native 920×700 ที่ 100%/125%, ไทย/อังกฤษ, ฟอนต์ฝัง, ภาพ alpha/JPG, สี/ความทึบ/มุม/ตำแหน่ง/ขนาด, หน้าหมุน/ขนาดต่างกัน/CropBox, pixel preview/export, Poppler, แก้ไขฟอร์ม, hash ต้นฉบับ/ผลเดิม, cancel/retry/error cleanup และ hidden worker/cache ในชุดทดสอบของรุ่นนี้

ผลเป็น Windows 10 เครื่องพัฒนา การจำกัด CPU affinity 2 logical cores ไม่รับรองเครื่องจริง RAM 4 GB/HDD ยังไม่ทดสอบ Windows 11 หรืออีกเครื่องจริง EXE/Installer ยัง unsigned; repository Private ต้องใช้บัญชีที่มีสิทธิ์ ไม่รับรอง peak memory ของเอกสารสแกนใหญ่/ภาพสูงสุด และการเปิดจาก HDD เย็น

แคช overlay สำหรับ export: ข้อความ≤8 / ภาพ≤2; ปิดทั้งหมดเมื่อสำเร็จ ผิดพลาด หรือยกเลิก.
