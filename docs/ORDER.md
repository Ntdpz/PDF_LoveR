# จัดเรียงหน้า PDF · 1.11.0

เปิด **จัดเรียงหน้า PDF** แล้วเลือก PDF หนึ่งไฟล์ ภาพตัวอย่างโหลดเฉพาะบริเวณที่มองเห็น
แต่ละการ์ดแสดง **ใหม่** (ตำแหน่งในผลลัพธ์) และ **เดิม** (เลขหน้าในต้นฉบับ)
ตารางทางขวาตรวจลำดับใหม่/เดิมและชื่อไฟล์ได้ครั้งละ 25 รายการ

- คลิกหน้าเพื่อเลือก; Ctrl+คลิกเพิ่ม/ลด และ Shift+คลิกเลือกช่วงตามลำดับใหม่
- ลากหน้าที่เลือกไปก่อนหรือหลังการ์ดปลายทาง เส้นสีน้ำเงินแสดงตำแหน่งแทรก
  ถ้าเลือกหลายหน้า หน้าที่เลือกจะย้ายพร้อมกันโดยรักษาลำดับระหว่างกัน
  เลื่อนที่ขอบบน/ล่างได้ และกด Esc เพื่อยกเลิกการลากก่อนปล่อย
- ลูกศร/Home/End/Page Up/Page Down เลื่อนจุดโฟกัส; Space เลือก/ลดหน้า
  Shift+ลูกศรเลือกช่วง, Ctrl+A เลือกทั้งหมด, Alt+ลูกศรย้ายหน้าที่เลือก
  หรือใช้ปุ่ม **ย้ายก่อน / ย้ายหลัง**; ช่องช่วงหน้าระบุตำแหน่งใหม่ เช่น `1-3,5`
- **คืนลำดับเดิม** คืนทุกหน้าและล้างการเลือก โดยยังไม่เขียนไฟล์
- เลือกชื่อและโฟลเดอร์ ตรวจตาราง แล้วกด **บันทึก PDF ตามลำดับใหม่** หรือ Ctrl+Enter

การบันทึกตรวจว่าทุกหน้าอยู่ครบครั้งเดียว เปิดต้นฉบับในหน่วยความจำและย้ายวัตถุหน้าเดิม
ไม่ rasterize ไม่เปลี่ยน DPI และไม่ลดคุณภาพ เนื้อหา/ภาพ/rotation/widgets/annotations
และ direct internal-link destinations คง page xref เดิม; bookmarks remap ไปยังลำดับใหม่
ไฟล์ชั่วคราวถูกเปิดตรวจจำนวนและลำดับ xref ก่อนเผยแพร่แบบไม่ทับไฟล์ที่มีอยู่
ตรวจ signature ต้นฉบับอีกครั้งก่อนเผยแพร่; ไม่เขียนกลับต้นฉบับ

**ยกเลิก** ใช้ loader และ token ร่วม รอ native operation ปัจจุบันจบแล้วล้าง staging
คืนเฉพาะไฟล์ของงานที่ยังไม่มีใครแก้ต่อ และคืน controls หลัง cleanup เพื่อเริ่มใหม่ได้
หากชื่อปลายทางมีอยู่แล้ว ให้เปลี่ยนชื่อก่อนเริ่มใหม่

หลักฐาน: [native interaction / Poppler](order-verification-1.11.0.json),
unit `tests/unit/test_pdf_order.py` ตรวจ link, bookmark, annotation, form value/การแก้ไข,
rotation, page text/pixels, cancellation/retry, collisions และการรักษาต้นฉบับ
ตรวจ 920×700 ที่ 100%/125% และ preview 240 หน้า; ใช้ process ร่วมหนึ่งตัว,
viewport ≤24, requests ≤16, cache 32/6 MiB โดยประมาณ

PDF ที่ต้องใช้รหัสผ่านและการรักษาความถูกต้องของลายเซ็นดิจิทัลยังไม่รองรับ
เอกสารที่มี JavaScript อ้างเลขหน้าตายตัวหรือ action พิเศษต้องตรวจพฤติกรรมใน PDF viewer
หลังเรียงใหม่; การย้ายหน้าไม่ rewrite script เหล่านั้น ไม่ได้เพิ่ม/ลบหน้าในเครื่องมือนี้
ยังไม่รับรอง PC 2 คอร์/4 GiB/HDD จริง หรือ Windows 11 จากผลเครื่องพัฒนา
