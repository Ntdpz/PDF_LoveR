# PDF LoveR 1.5.0

เพิ่ม **หมุน PDF** รวมเป็น 6 เครื่องมือพร้อมใช้จาก 34 เครื่องมือ เหลือพัฒนา 28

- หมุนเพิ่ม 90/180/270 องศา ทุกหน้าหรือหน้าที่เลือก รองรับหลายไฟล์
- ตัวเลือกหน้าแยกต่อเอกสาร ภาพก่อน–หลัง และรายการชื่อไฟล์ก่อนบันทึก
- เก็บทุกหน้าตามลำดับเดิม ฟอร์ม ลิงก์ หมายเหตุ บุ๊กมาร์กและเอกสารแนบ
- ตรวจทั้งชุดก่อนเผยแพร่ ไม่ทับไฟล์เดิม และคืนเฉพาะไฟล์ของงานเมื่อบันทึกล้มเหลว
- เพิ่ม shared PagePreview และแชร์ publication/rollback กับแยกหน้า/ลบหน้า

ชุดแจก: `dist/PDF_LoveR_1.5.0/` มี EXE, Portable ZIP, installer, คู่มือไทยและ SHA256
repository คง Private และไม่ได้สร้าง GitHub Release
