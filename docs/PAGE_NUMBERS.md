# ใส่หมายเลขหน้า PDF · 1.12.0

เลือก PDF หนึ่งไฟล์ แล้วเลือกทุกหน้าหรือช่วง เช่น `1-3,5,8-10` ด้วยตัวเลือกหน้าร่วม
เลือกแท็บ **ตรวจภาพเลข** เพื่อดูต้นฉบับ/ผลลัพธ์ และกดก่อนหน้า/ถัดไปดูเฉพาะหน้าที่เลือก
ภาพตัวอย่างเรนเดอร์ด้วยขั้นตอนวางเลขเดียวกับไฟล์ผลลัพธ์ เป็นภาพย่อ ไม่มีซูมเต็มหน้า
ข้อความใต้ภาพระบุหน้าเดิมและเลขที่จะพิมพ์; PDF ใหม่เก็บทุกหน้าตามลำดับเดิม

| ตั้งค่า | ความหมาย |
|---|---|
| ตามลำดับหน้าเดิม | เลขเริ่มต้น + (หมายเลขหน้าเดิม − 1) |
| ต่อเนื่องเฉพาะหน้าที่เลือก | เลขเริ่มต้น + ลำดับในชุดที่เลือก เริ่มลำดับที่ 0 |
| รูปแบบ | `1`, `หน้า 1`, `1 / 10`; เลือกใช้เลขไทยได้ |
| ตัวหาร `/` | จำนวนหน้าทั้ง PDF ในโหมดหน้าเดิม หรือจำนวนหน้าที่เลือกในโหมดต่อเนื่อง |
| เลขเริ่มต้น | จำนวนเต็ม 1–999999; ตัวหารไม่เปลี่ยนตามเลขเริ่มต้น |
| ตำแหน่ง | บน/ล่าง × ซ้าย/กลาง/ขวา ในหน้าที่มองเห็นหลังหมุนและ CropBox |
| ขนาด/สี | 6–72 pt และ `#RRGGBB` เช่น `#003366` |

ตัวอย่าง PDF 10 หน้า เลือกหน้า 2 และ 5 เริ่มที่ 3:
โหมดหน้าเดิมได้ `4 / 10`, `7 / 10`; โหมดต่อเนื่องได้ `3 / 2`, `4 / 2`
ตัวหารเป็นจำนวนหน้า จึงอาจน้อยกว่าตัวเลขเมื่อกำหนดเลขเริ่มต้นเอง
ขอบห่าง 12 pt; กล่องข้อความสูง 2.4 เท่าของขนาดตัวอักษร
หมายเลขใหญ่เกินหน้าจะถูกปฏิเสธโดยไม่ลดขนาดเอง

ฟอนต์ Noto Sans Thai ฝังอยู่ใน PDF พร้อมข้อมูล Unicode และ shaping ภาษาไทย
มาจาก [Google Fonts](https://github.com/google/fonts/tree/main/ofl/notosansthai)
แจกตาม SIL Open Font License 1.1 พร้อมไฟล์ `assets/fonts/OFL.txt`
ไม่ใช้ฟอนต์ไทยของ Windows ในผลลัพธ์ และไม่ต้องติดตั้งฟอนต์นี้เพื่ออ่าน PDF
ตรวจ embedded font bytes และเรนเดอร์ด้วย Poppler แยกจาก PyMuPDF แล้ว;
ยังไม่ได้เปิดผลบนคอมพิวเตอร์จริงอีกเครื่อง

ตั้งชื่อและโฟลเดอร์ที่มีอยู่ แล้วกดบันทึกหรือ Ctrl+Enter; Ctrl+O เลือก PDF
Tab เลื่อน focus, Enter/Space เปิดเมนู, ตัวเลือกหน้ารองรับลูกศร/Shift/Ctrl/Space ตามคู่มือเลือกหน้า
กด **ยกเลิก** แล้วรอ native call ปัจจุบันจบและ cleanup ก่อนเริ่มใหม่
ไฟล์ชื่อชน ต้นฉบับ/alias หรือข้อมูลเปลี่ยนหลังอ่านจะถูกปฏิเสธ
บันทึกในพื้นที่ชั่วคราว ตรวจจำนวนหน้า/geometry และเผยแพร่แบบ exclusive
ไม่แก้ต้นฉบับหรือทับผลเดิม; จบงานแล้วเปลี่ยนชื่อก่อนสร้างไฟล์อีกครั้ง

เนื้อหาเดิมยังเป็นข้อความ เวกเตอร์ และภาพเดิม เพิ่มเฉพาะ vector overlay
รวม font streams ที่ซ้ำกันโดยไม่ลดคุณภาพ; links/bookmarks/annotations และฟอร์มที่แก้ค่าได้ผ่านการทดสอบ
หมายเลขอาจทับเนื้อหาเดิมในตำแหน่งที่เลือก จึงควรตรวจทุกหน้าที่เกี่ยวข้อง
ไม่รองรับ PDF มีรหัสผ่านหรือรักษาความถูกต้องของลายเซ็นดิจิทัลหลังเพิ่มเนื้อหา
ไม่แก้ page labels เดิม/JavaScript/ข้อความเลขหน้าที่มีอยู่ และไม่ใช่การลบข้อมูลลับ

ใช้ preview coordinator ร่วมหนึ่ง process, render เฉพาะหน้าที่ตรวจ
selector cache 32/6 MiB; before/after cache 12/6 MiB โดยประมาณ
worker events จำกัด 32, อ่านไม่เกิน 100 ต่อรอบ, export ทีละงาน ไม่เพิ่ม runtime dependency
การวัด CPU affinity สอง logical cores เป็นหลักฐานจำกัด ไม่รับรอง PC 4 GB/HDD หรือ Windows 11
