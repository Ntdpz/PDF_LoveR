# PDF to Image · 1.9.0

เพิ่ม PDF แล้วเลือกโฟลเดอร์ปลายทาง ประเภทภาพ และขนาด จากนั้นกดเริ่มแปลงเป็นภาพ
หนึ่งภาพต่อหน้าที่เลือก หนึ่งโฟลเดอร์ต่อ PDF ไม่แก้ต้นฉบับและไม่ทับผลลัพธ์เดิม

- PNG, WebP และ TIFF ใช้ Lossless รักษาพิกเซลของภาพที่เรนเดอร์
- JPG ใช้คุณภาพที่กำหนด 1–100 (เริ่ม 95) มีการสูญเสียคุณภาพแม้ตั้ง 100
- DPI: 36–600 (เริ่ม 150) กำหนดจำนวนพิกเซลตามขนาดหน้าเอกสาร
- พิกเซล: ใส่ความกว้างหรือความสูงอย่างน้อยหนึ่งช่อง 1–20000 px
  รักษาสัดส่วนเสมอ ใส่สองช่องเป็นกรอบสูงสุด เช่น หน้า 2:1 ในกรอบ 1000×1000 ได้ 1000×500
  กำหนดขนาดจาก PDF โดยตรง; ขอบเศษพิกเซลปรับด้วย LANCZOS ให้ตรงขนาดที่คำนวณ
  เพิ่มพิกเซลไม่เพิ่มรายละเอียดที่หายไปจากภาพต้นฉบับ
- ภาพเกิน 40 ล้านพิกเซลจะขึ้นข้อผิดพลาด โปรแกรมไม่ลดขนาดให้เอง
- เพดานไฟล์: ใส่จำนวนบวกเป็น KB หรือ MB ต่อภาพ เว้นว่างเพื่อไม่จำกัด
  1 KB = 1024 bytes และ 1 MB = 1048576 bytes; ต้องไม่น้อยกว่า 1 byte

เพดานไฟล์เป็นเป้าหมายสำหรับตรวจผล ไม่ใช่การรับประกันขนาดสูงสุด
หากไฟล์เกินเพดาน โปรแกรมยังบันทึกตามค่าที่เลือกแล้วแจ้งเตือน ไม่ลดคุณภาพหรือพิกเซลเอง
กดดูคำเตือนเพื่อดูชื่อและขนาดจริง (แสดงไม่เกิน 50 รายการ แต่จำนวนรวมครบ)
ทุกโฟลเดอร์มี `image_report.csv` ระบุชื่อภาพ กว้าง/สูง bytes เพดาน และเกินเพดานหรือไม่
หากต้องการไฟล์เล็กลง ให้ผู้ใช้เลือกขนาด/คุณภาพ JPG ใหม่อย่างชัดเจนก่อนแปลงอีกครั้ง
PNG/WebP/TIFF ไม่มีการลดคุณภาพแบบอัตโนมัติ

PDF มีรหัสผ่านต้องปลดล็อกก่อน เลือกหน้าแต่ละ PDF ได้ผ่านปุ่ม “เลือกหน้า”
กรณีงานล้มเหลว หน้าที่บันทึกสำเร็จแล้วอาจยังอยู่พร้อม CSV ที่ไม่ครบ ดูข้อผิดพลาดก่อนนำไปใช้
รูปจะเรนเดอร์พื้นหลังขาว RGB ไม่รองรับพื้นหลังโปร่งใสหรือ TIFF หลายหน้า

## เลือกหน้าก่อนแปลง

ค่าเริ่มต้นคือทุกหน้า กด **เลือกหน้า** ข้าง PDF เพื่ออ่านจำนวนหน้าและเปิดภาพตัวอย่าง
เลือกทุกหน้า หรือพิมพ์ช่วง เช่น `1-3,5,8` หรือคลิกภาพตัวอย่าง; Shift/Ctrl และลากครอบใช้ได้
ต้องเลือกอย่างน้อยหนึ่งหน้า ช่วงต้องเรียงจากน้อยไปมาก ไม่ซ้ำ และไม่เกินจำนวนหน้าจริง
กด **ยืนยันหน้าที่เลือก** เพื่อเก็บค่าเฉพาะไฟล์นั้น ปิดหน้าต่างเพื่อยกเลิกการแก้ไข
การสลับเครื่องมือเก็บค่าที่เลือกไว้ การลบ PDF หรือล้างรายการจะล้างค่าของไฟล์นั้น

ตัวอย่าง: เลือกหน้า 2 และ 5 ได้ `ชื่อเอกสาร_page_002.png` และ `ชื่อเอกสาร_page_005.png`
ชื่อภาพคงเลขหน้าต้นฉบับทุกประเภทภาพ CSV มีเฉพาะภาพที่แปลง และความคืบหน้านับเฉพาะหน้าที่เลือก
หากต้นฉบับเปลี่ยนหลังยืนยัน โปรแกรมจะปฏิเสธไฟล์นั้นก่อนสร้างโฟลเดอร์ผลลัพธ์
ให้เปิดเลือกหน้าใหม่เพื่อตรวจเอกสารอีกครั้ง รายการอื่นยังแปลงต่อได้

ภาพตัวอย่างแสดงเฉพาะหน้าที่มองเห็น ไม่ลด DPI หรือพิกเซลของไฟล์ผลลัพธ์
