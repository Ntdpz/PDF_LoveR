PDF to PNG 1.0.0 — วิธีนำไปใช้เครื่องอื่น
สำหรับ Windows 10 / 11 แบบ 64-bit

1. แบบไฟล์เดียว (แนะนำเมื่อต้องการเปิดทันที)
   ไฟล์: PDF_to_PNG.exe
   คัดลอกไฟล์นี้ไปอีกเครื่อง แล้วดับเบิลคลิกเปิดได้เลย
   ไม่ต้องติดตั้ง Python หรือโปรแกรมอ่าน PDF และไม่ต้องใช้เน็ต
   ตอนเปิดโปรแกรมจะแตกไฟล์ที่จำเป็นลงโฟลเดอร์ชั่วคราวโดยอัตโนมัติ
   เปิดครั้งแรกอาจใช้เวลาสักครู่

2. แบบติดตั้ง
   ไฟล์: PDF_to_PNG_Setup_1.0.0.exe
   เปิดไฟล์แล้วทำตามขั้นตอนติดตั้ง มีทางลัดใน Start Menu
   เลือกสร้างทางลัดบน Desktop ได้
   ติดตั้งสำหรับผู้ใช้ปัจจุบัน ไม่ต้องขอสิทธิ์ Administrator
   ถอนการติดตั้งได้จาก Settings > Apps ของ Windows

3. แบบ ZIP โฟลเดอร์ (เปิดเร็วกว่าแบบไฟล์เดียว)
   ไฟล์: PDF_to_PNG_Portable_Folder_1.0.0.zip
   แตก ZIP ทั้งหมด แล้วเปิด PDF_to_PNG_Modern.exe ภายในโฟลเดอร์
   เก็บโฟลเดอร์ _internal ไว้ข้าง EXE เสมอ

การใช้งาน
   กดเพิ่ม PDF > เลือกโฟลเดอร์ปลายทาง > เริ่มแปลงเป็น PNG
   Ctrl + O เพิ่ม PDF, Ctrl + Enter เริ่มแปลง
   เปลี่ยนความละเอียดได้ 36–600 DPI ค่าเริ่มต้น 150 DPI
   หนึ่งโฟลเดอร์ต่อหนึ่ง PDF พร้อมเลขหน้าในชื่อภาพ
   ถ้าชื่อโฟลเดอร์ซ้ำ จะสร้างชื่อใหม่โดยไม่ทับผลลัพธ์เดิม

การถอนการติดตั้งไม่ลบภาพที่คุณแปลงไว้
ไฟล์ชุดนี้ไม่มีการลงทะเบียนเป็นโปรแกรมเปิด PDF เริ่มต้น
