รวม PDF
  เลือกเครื่องมือรวม PDF > เพิ่มอย่างน้อย 2 ไฟล์
  ลาก PDF จาก File Explorer มาวางที่ไหนก็ได้ในหน้าต่างเพื่อเพิ่มไฟล์
  วางไฟล์ในหน้าแรกจะเปิดเครื่องมือรวม PDF ให้โดยอัตโนมัติ
  กดค้างบนการ์ดแล้วลากเพื่อเปลี่ยนลำดับ ซ้ายไปขวาแล้วขึ้นแถวใหม่
  ลากใกล้ขอบบน/ล่างเพื่อเลื่อนรายการอัตโนมัติ กด Esc เพื่อยกเลิกการลาก
  กด Tab เพื่อโฟกัสการ์ด แล้วใช้ลูกศรเพื่อจัดลำดับได้ด้วย
  เลือกที่บันทึกด้วยชื่อใหม่ > รวมและบันทึก PDF
  รวมทุกหน้า ไม่เขียนทับไฟล์เดิม ไม่รองรับ PDF ที่ต้องใช้รหัสผ่าน

แยก PDF
  เลือก PDF หนึ่งไฟล์ > เลือกหนึ่งไฟล์ต่อหน้า / ตามช่วง / ทุก N หน้า
  ตามช่วง: 1-3,5,8-10 ได้ 3 ไฟล์; เรียงจากน้อยไปมากและไม่ซ้ำ
  ทุก N หน้า: หน้าท้ายที่เหลือเป็นไฟล์สุดท้าย
  ดู thumbnails ช่วงหน้าและชื่อไฟล์ > ตั้งชื่อชุดไฟล์/โฟลเดอร์ > แยกและบันทึก PDF
  ไม่ทับต้นฉบับหรือชื่อไฟล์เดิม ไม่รองรับรหัสผ่าน

แยกหน้า
  เลือก PDF หนึ่งไฟล์ > เลือกภาพหน้า หรือช่วง เช่น 1-3,5,8-10
  รวมทุกหน้าที่เลือกเป็น PDF เดียว หรือหนึ่งไฟล์ต่อหน้า
  ตรวจเลขหน้าใหม่เทียบหน้าเดิมและชื่อไฟล์ > ตั้งชื่อ/โฟลเดอร์ > บันทึกหน้าที่เลือก

ลบหน้าออก
  เลือก PDF หนึ่งไฟล์ > เลือกหน้าที่จะลบ > ตรวจหน้าที่เหลือ
  ต้องเหลืออย่างน้อยหนึ่งหน้า > ตั้งชื่อ/โฟลเดอร์ > ลบหน้าและบันทึกไฟล์ใหม่
  ต้นฉบับและไฟล์ที่มีอยู่แล้วจะไม่ถูกเขียนทับ

หมุน PDF
  เพิ่ม PDF หลายไฟล์ > เลือกเอกสารในรายการเพื่อเลือกหน้าของแต่ละไฟล์
  กดไอคอนหมุนซ้ายหรือขวา ครั้งละ 90 องศา; กดซ้ำเพื่อหมุนเพิ่มจากมุมเดิม
  ดูภาพก่อน–หลังและชื่อไฟล์ทั้งหมด > ตั้งข้อความต่อท้าย/โฟลเดอร์ > บันทึกเป็น PDF ใหม่

PDF to Image
  เพิ่ม PDF > เลือกโฟลเดอร์ปลายทาง > เริ่มแปลงเป็นภาพ
  ลาก PDF มาวางในหน้านี้เพื่อเพิ่มเข้าเครื่องมือแปลงภาพได้ด้วย
  เลือก PNG / JPG / WebP / TIFF และ DPI 36–600 หรือความกว้าง/สูงเป็นพิกเซล
  ล็อกสัดส่วนเสมอ ใส่สองช่องเป็นกรอบสูงสุด ไม่เกิน 40 ล้านพิกเซล
  PNG / WebP / TIFF เป็น Lossless; JPG มีการสูญเสียคุณภาพ (ตั้ง 1–100 ได้)
  กำหนดเพดาน KB/MB ต่อภาพได้ (เว้นว่าง = ไม่จำกัด)
  เกินเพดานจะบันทึกตามคุณภาพที่เลือกแล้วแจ้งเตือน ไม่ลดคุณภาพหรือพิกเซลเอง
  ดูขนาดจริงใน image_report.csv หนึ่งโฟลเดอร์ต่อเอกสาร

Ctrl + O เพิ่ม PDF · Ctrl + Enter เริ่มทำงาน · Alt + Left กลับหน้าแรก
เครื่องมืออื่นที่แสดง “กำลังเตรียม” ยังไม่พร้อมใช้งาน

ปุ่มหมุนเป็นไอคอนลูกศรโค้งซ้าย/ขวา กดทีละ 90° เริ่มที่ทิศเดิม
กดสองครั้งกลับหัว สี่ครั้งกลับทิศเดิม; ชี้เมาส์หรือโฟกัสปุ่มเพื่อดูคำอธิบาย

รุ่นนี้คืนหน่วยความจำของภาพตัวอย่างเมื่อเปลี่ยนเครื่องมือหรือกลับหน้าแรก
รายการไฟล์และค่าที่ตั้งไว้ยังอยู่ คุณภาพไฟล์ที่บันทึกใช้ค่าที่คุณเลือก
ใช้เป็นประจำแนะนำแบบติดตั้งหรือ Portable ZIP

ภาพหน้าเอกสารเรียงหลายแถว เลื่อนลงด้วยลูกล้อเมาส์หรือแถบเลื่อนด้านขวา

เลือกหลายหน้า: Shift+คลิกเลือกช่วง · Ctrl+คลิกเพิ่ม/ลด · ลากครอบเลือกหลายหน้า
ลากถึงขอบบน/ล่างเพื่อเลื่อนต่อ; Esc ยกเลิกการลาก; ปล่อยเมาส์เพื่อยืนยัน

หน้าจอตรวจเอกสาร
  หน้าแรกเริ่มด้วย 6 เครื่องมือพร้อมใช้; เครื่องมือในแผนระบุว่ายังไม่พร้อมใช้
  แยก PDF / แยกหน้า / ลบหน้า: เอกสารซ้าย ตั้งค่าและตรวจชื่อผลลัพธ์ขวา บันทึกด้านล่าง
  เลื่อนตารางหน้าแนวตั้งเพื่อเลือกหน้าถัดไป และเลื่อนตารางชื่อไฟล์เมื่อต้องตรวจหลายรายการ
  หมุน PDF: สลับแท็บต้นฉบับ / ผลลัพธ์ เลื่อน panel ด้านขวาลงเพื่อตั้งชื่อและปลายทาง
  ชื่อไฟล์ยาวในช่องแก้ไขเลื่อนด้วยลูกศร/Home/End; ภาพตัวอย่างใช้ช่วยเลือกหน้า ไม่มีซูมเต็มหน้า
  ปรับหน้าต่างขั้นต่ำ 920×700; ตรวจบน Windows 10 เครื่องพัฒนาที่ scaling 100% และ 125%
  ยังไม่ทดสอบบน PC 2 คอร์ / RAM 4 GiB / HDD หรือ Windows 11 จริง

โต๊ะเอกสารรุ่นใหม่
  หน้าแรกเต็มความกว้าง แสดงงานหลักทั้ง 6 งาน ไม่ต้องเลื่อนหา
  หมวดเครื่องมือเลือกจาก dropdown ข้างช่องค้นหา
  ทุกหน้ามีเมนูเปลี่ยนเครื่องมือด้านบน โดยเก็บเอกสารและค่าของแต่ละงานไว้
  รุ่นแสดงใน title bar และหน้าแรก ตรวจว่าเปิด EXE รุ่น {{VERSION}}
