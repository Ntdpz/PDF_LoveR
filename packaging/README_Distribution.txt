Windows 10 / 11 แบบ 64-bit · ทำงานออฟไลน์ · ไม่ต้องติดตั้ง Python
ปลายทางเริ่มต้น: Documents ของผู้ใช้ เปลี่ยนได้จากปุ่มเลือกที่บันทึก

เปิดได้ทันที
  PDF_LoveR_{{VERSION}}.exe
  คัดลอกไฟล์เดียวไปอีกเครื่องแล้วดับเบิลคลิก เปิดครั้งแรกอาจใช้เวลาสักครู่

ติดตั้งพร้อมทางลัด
  PDF_LoveR_{{VERSION}}_Setup.exe
  ติดตั้งสำหรับผู้ใช้ปัจจุบัน ไม่ต้องใช้สิทธิ์ Administrator
  ถอนการติดตั้งผ่าน Settings > Apps โดยไม่ลบผลลัพธ์ที่คุณสร้างไว้

แบบโฟลเดอร์
  PDF_LoveR_{{VERSION}}_Portable.zip
  แตก ZIP ทั้งหมด แล้วเปิด PDF_LoveR_{{VERSION}}.exe ภายในโฟลเดอร์
  เก็บโฟลเดอร์ _internal ไว้ข้าง EXE เสมอ

รวม PDF
  เลือกเครื่องมือรวม PDF > เพิ่มอย่างน้อย 2 ไฟล์
  ลาก PDF จาก File Explorer มาวางที่ไหนก็ได้ในหน้าต่างเพื่อเพิ่มไฟล์
  วางไฟล์ในหน้าแรกจะเปิดเครื่องมือรวม PDF ให้โดยอัตโนมัติ
  กดค้างบนการ์ดแล้วลากเพื่อเปลี่ยนลำดับ ซ้ายไปขวาแล้วขึ้นแถวใหม่
  ลากใกล้ขอบบน/ล่างเพื่อเลื่อนรายการอัตโนมัติ กด Esc เพื่อยกเลิกการลาก
  กด Tab เพื่อโฟกัสการ์ด แล้วใช้ลูกศรเพื่อจัดลำดับได้ด้วย
  เลือกที่บันทึกด้วยชื่อใหม่ > รวมและบันทึก PDF
  รวมทุกหน้า ไม่เขียนทับไฟล์เดิม ไม่รองรับ PDF ที่ต้องใช้รหัสผ่าน

แยก PDF
  เลือก PDF หนึ่งไฟล์ > เลือกหนึ่งไฟล์ต่อหน้า / ตามช่วง / ทุก N หน้า
  ตามช่วง: 1-3,5,8-10 ได้ 3 ไฟล์; เรียงจากน้อยไปมากและไม่ซ้ำ
  ทุก N หน้า: หน้าท้ายที่เหลือเป็นไฟล์สุดท้าย
  ดู thumbnails ช่วงหน้าและชื่อไฟล์ > ตั้งชื่อชุดไฟล์/โฟลเดอร์ > แยกและบันทึก PDF
  ไม่ทับต้นฉบับหรือชื่อไฟล์เดิม ไม่รองรับรหัสผ่าน

แยกหน้า
  เลือก PDF หนึ่งไฟล์ > เลือกภาพหน้า หรือช่วง เช่น 1-3,5,8-10
  รวมทุกหน้าที่เลือกเป็น PDF เดียว หรือหนึ่งไฟล์ต่อหน้า
  ตรวจเลขหน้าใหม่เทียบหน้าเดิมและชื่อไฟล์ > ตั้งชื่อ/โฟลเดอร์ > บันทึกหน้าที่เลือก

ลบหน้าออก
  เลือก PDF หนึ่งไฟล์ > เลือกหน้าที่จะลบ > ตรวจหน้าที่เหลือ
  ต้องเหลืออย่างน้อยหนึ่งหน้า > ตั้งชื่อ/โฟลเดอร์ > ลบหน้าและบันทึกไฟล์ใหม่
  ต้นฉบับและไฟล์ที่มีอยู่แล้วจะไม่ถูกเขียนทับ

PDF เป็น PNG
  เพิ่ม PDF > เลือกโฟลเดอร์ปลายทาง > เริ่มแปลงเป็น PNG
  ลาก PDF มาวางในหน้านี้เพื่อเพิ่มเข้าเครื่องมือแปลงภาพได้ด้วย
  ตั้งความละเอียดได้ 36–600 DPI หนึ่งโฟลเดอร์ต่อเอกสาร

Ctrl + O เพิ่ม PDF · Ctrl + Enter เริ่มทำงาน · Alt + Left กลับหน้าแรก
